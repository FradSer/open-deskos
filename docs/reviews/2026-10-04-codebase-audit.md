# 2026-10-04 代码与测试检查

## 范围与结论

本轮检查覆盖 Shell、Personal Bot、外部集成、Remote/Camera 外设、研究固件、Apple 工具和构建脚本。已修复能够复现的问题，删除确认未被使用的代码和重复测试设施，并保留不同场景的行为断言。检查和验证均在本机或隔离夹具中进行。

起始盘点包含 1,914 个现存受版本控制的文件，其中包含第三方源码。检查结合文件盘点、静态检查、模块人工审阅、现有测试和新增回归；没有逐行审阅全部第三方代码，也没有完成所有支持平台的实机验收。

| 范围 | 实际覆盖 |
| --- | --- |
| Shell | 主进程、preload、应用存储与验证、控制通道、服务生命周期、平台边界；Desk Data、Pi Sessions、Hydra 相关路径；脚本、配置和完整 Node 测试入口 |
| Personal Bot | 43 个应用源模块的审阅，意图路由、任务、主动建议、私有状态和通道边界；完整测试入口和类型检查 |
| 集成与外设 | Futu、STT、Remote Bridge 的传输及配置边界；S3 帧解析、描述符生成和固件构建；P4 Camera 的源代码检查 |
| 研究代码 | 领域版本匹配、应用管理与生成管线、选定 C 模块静态分析、主机 C/Lua 检查；Apple CLI 与管理夹具；Web 前端构建 |

工作区同时存在文档整合、Desk Link 和原生 Pi 会话控制等并行修改。本轮保留这些修改，没有重置、暂存或提交它们；其文档删除和功能实现不计入本轮清理成果。

## 修复

| 问题 | 修复后的行为与验证 |
| --- | --- |
| Shell 退出时异步启动继续创建窗口、定时器或监听器 | 在异步步骤之后检查退出状态；退出后才完成的监听立即关闭。增加生命周期回归。 |
| Futu 服务在启动、刷新、停止交错时重新开放监听 | 生命周期操作顺序执行，停止不会留下随后恢复的监听；仍支持明确重新启动。 |
| 目录读取失败或声明移除后，服务与 Desk Data 注册状态错误 | 目录读取成功才替换服务声明；移除声明时撤回监听与数据注册，读取失败保留现有有效状态。 |
| 已安装 Widget 因新布局占用、页面变化或范围变化而阻断整个目录 | 按 Widget 返回位置错误；更新和回滚保留已存位置，新位置请求仍校验冲突。损坏的位置字段继续拒绝。 |
| 应用目录的服务、数据声明可独立于验证快照被篡改 | 与快照中的规范化声明进行结构比较；新增、移除、改写均拒绝，JSON 属性排序变化允许。新增实际目录读写回归。 |
| 未认证客户端长期占用需要 token 的通道 | 认证握手有独立期限；通过认证、拒绝或断开时清理定时器。Unix 所有权认证的空闲连接不受此期限影响。 |
| 带换行的超长 token 握手绕过长度上限 | 检查认证行本身的字节长度；所有权认证的大协议帧及正常握手后的大数据仍可传输。 |
| 并行应用验证共享 Electron profile | 每次验证拥有独立临时目录与 profile；成功、超时、取消和启动失败均清理。取消发生在启动回调内也不会遗留期限定时器。 |
| 验证进程关闭之前耗尽了清理重试 | 进程关闭后重新给予有界清理机会，覆盖 Windows 文件锁延迟释放的模拟回归。真实 Windows 文件锁行为尚未实机验证。 |
| 主动建议读取错误的全局超时配置 | 显式服务环境优先；传入空环境时不继承全局值。测试真实入口的超时和有效返回行为。 |
| 候选检查测试把进程启动耗时误判为输出排空失败 | 调整夹具启动预算，继续断言超时、截断、输出尾部和路径隔离。 |
| 原生 Pi 集成测试继承了宿主会话目录 | helper 显式指定夹具自己的临时会话目录；保留真实 helper 与 SessionHost 通道断言，未修改外部 Pi 仓库。 |
| Pi 交互夹具遗漏模拟接口，手柄检查只记录页面意图 | 补齐天气、Futu 的未配置响应；Y 键必须实际调用模拟主进程 toggle 接口，返回未接受且不触及麦克风。加强断言先失败，补齐接口后 34 项通过。 |
| Futu TCP EOF 未及时使客户端失效 | EOF 返回失败并关闭旧连接，下一次轮询重新连接；真实传输回归覆盖此过程。 |
| STT 安装脚本在特权操作之后才发现端口无效 | 在权限检查与安装之前校验端口范围；测试使用假的权限检查，避免触及真实安装。 |
| 研究 semver 接受无效数字与尾逗号，错误处理零主版本 caret 范围 | 严格拒绝无效输入，按首个非零版本段确定上界，避免上界计算溢出；新增表格回归。语义参考 [node-semver caret 范围](https://github.com/npm/node-semver#caret-ranges-123-025-004)。 |
| 描述符把不同插件 ID 转换成相同或非法 C 标识符 | 私有符号使用列表索引；保留公共插件 ID。现有测试扩展为生成、实际 C 编译和执行读取。 |
| S3 状态帧静默截断动作字段、接受 JSON 后的多余内容 | 长度超限或整行无效时拒绝，不改动已有状态；纯解析模块直接进入主机 C 测试，并通过实际 ESP-IDF 构建。 |

行为修复先写入相应 `.feature` 场景，再用回归测试复现失败，完成修复后重跑。跨模块与安全边界由没有实现历史的新代理复核。S3 构建中曾错误引用旧 SDK 组件名称，移除该多余引用后重建通过。

## 删除和合并的冗余

- 删除未使用的 Desk Data 常量、Hydra HTML 转义函数、Pi Sessions 闭包、前端类型别名和 Python 导入。
- 删除未调用的 Widget 测试帮助函数；保留并运行实际身份连续性、焦点与滚动检查。
- 描述符生成器删除不再需要的 ID 清洗函数，降低代码量并消除符号碰撞。
- Apple CLI 测试的两个重复固定端口服务器合并为一个临时端口夹具；保留三个请求检查，使用就绪探测，验证服务器完成且执行清理。
- S3 主机解析测试复用已有 cJSON 测试依赖，没有引入第二份依赖副本。

精确重复扫描没有发现相同测试体。具有不同输入、平台或失败边界的测试仍然有价值，未按名称或相似外观删除。本轮没有以减少已执行行为检查的方式压缩测试数量。
