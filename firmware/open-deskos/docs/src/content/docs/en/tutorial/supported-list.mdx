## Supported production board

Open DeskOS firmware supports only the Guition JC4880P443C
(ESP32-P4 + ESP32-C6, 480×800).

See <LinkToSource relativePath="application/open_deskos/boards/guition/jc4880p443c/" />.

Other ESP-Claw boards, chips, and board-manager examples are not supported
production targets in this firmware tree.
