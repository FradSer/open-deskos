## 支持的生产硬件

Open DeskOS 固件只支持 Guition JC4880P443C
（ESP32-P4 + ESP32-C6，480×800）。

请见 <LinkToSource relativePath="application/open_deskos/boards/guition/jc4880p443c/" />。

其他 ESP-Claw 芯片、开发板和 board-manager 示例都不是当前固件支持的生产目标。
